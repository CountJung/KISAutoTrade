## 1. 바로 진행할 코드·개선 작업

즉시 자동 구현은 **3개**다. 2026-11-07 사용자가 제안 반영을 요청해 단일 활성 계좌와 위험 행동 확인 방향을 확정했다. 아래 항목은 남은 구현·검증이며, 이번 목록 갱신이 기능 완료나 실제 거래 실행을 뜻하지 않는다. 기존 즉시10회차·UI/UX9개·키보드5개의 완료 근거는 [완료 이력](completed-history.md)을 따른다.

**실행 순서:** P1-SCOPE-01의 남은 격리 조건은 유지하며, 완료한 [P2-UX-07 확인 흐름](completed-history.md#p2-ux-07)을 바탕으로 완료한 [P1-SESSION-01 정규장·DST](completed-history.md#p1-session-01) 기준 재사용 → P1-DATA-01의 KIS/Toss 수집 확대 → P2-SECTOR-01의 확보 자료 비교·한계 표시 → 4구역의 실제 장중·장기 검증. 각 작업은 관련 mock/fixture와 문서 게이트, 독립 리뷰를 마친 뒤 해당 작업 브랜치에 커밋·푸시한다. 실제 자료가 부족해도 독립적인 코드·합성 검증까지 함께 대기시키지 않는다.

**공통 범위:** 새 앱 자료 경로는 한국투자증권·토스증권 차트만 사용한다. 미국 모의 거래는 정규장만 처리하며 데이·프리·애프터 확장은 이번 범위 밖이다. 근사 가격·지연/누락·배당 미반영·체결 가정을 표시하고 실제 주문 성과나 총수익으로 부르지 않는다. 모의와 실전의 계좌/모드·원장·실행 경계를 분리하고 기존 동의·preflight·scope·risk·중복 방지·예약 guard를 유지한다. 실제 계좌·주문·운영 DB·배포는 이 목록으로 승인되지 않는다.

DB 이관과 SQLx/MSRV는 2~3구역, 서명·자동 업데이트는 P3-SIGN-01의 별도 결정이다. 기본 JSON 저장을 유지하되 이미 선택한 사용자의 DB 설정을 임의로 되돌리지 않는다. Xcode27.0→27.1의 기존 보류도 유지한다.
