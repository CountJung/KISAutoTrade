## 손익과 비용에서 확인한 개선 근거

1. **완료 거래와 기말 보유분을 분리해야 한다.** 강한 종가는 완료 50회 모두 손실이지만 44/45창에 포지션이 남았고, 15창은 총 평가이익과 실현손실의 부호가 반대다. 추세 필터의 완료 22회·돌파 실패의 43회도 모두 손실이다. 이익 보유분을 계속 보유하는 청산 설계가 영향을 주므로 완료 승률만으로 전략 가치를 단정하지 않는다. `잔여 평가손익 = 총 평가손익 − 실현손익`으로 기록하며, 열린 포지션의 매수 비용도 포함하므로 순수 가격차 미실현손익과 구분한다. 기말 가정 청산 비용은 아직 적용하지 않았다.
2. **반복 신호가 많다.** 모멘텀은 무보유 매도 차단 238건, 이격도는 신호 421건 중 차단 386건(무보유 매도 293·보유 중 매수 93), RSI는 무보유 매도 117건이다. 차단 자체는 guard가 작동한 결과다. 주문 방어를 완화하지 않고 전략 상태·임계값 교차·실행 피드백을 검증해 raw 중복을 줄인다.
3. **비용 스트레스가 손익 부호와 매매 경로를 바꾼다.** 양수→0 이하로 바뀐 완전 창은 연속 5, 가격조건 3, 평균회귀·추세·강한 종가 각 1, 합계 11창이다. 연속 전략의 중앙값은 +0.0482%→-0.0424%다.
4. **체결가에 따른 손절 경로 사례:** QQQ 2026Q3 평균회귀는 두 비용 모두 7월 17일 매수한다. 기본 체결가 $696.0253에서는 9월 21일 상단 밴드 청산으로 +0.6274%, 스트레스 체결가 $696.7207에서는 7월 29일 -5.02% 손절로 -0.5659%다. 이는 단순 비용 차감 이상의 피드백이다. 종가-only 손절이 장중 손실 5% 상한을 보장하는 것은 아니다.

최근 248봉 창에서도 예를 들어 SOXQ 추세 필터는 +9.6300%지만 완료 거래 0회이고, 변동성 확장은 -2.2872%다. 이 보조 창은 분기 집계와 겹치며 '새 독립 표본'으로 더하지 않는다.

## 재현과 검증

프로젝트 내부 ignored `.cache/research/strategy-review-20261018/`에 다음 standalone manifest를 두고 루트 Cargo.lock을 복사해 시작했다. package/version/source 비교 결과 production 의존성 변경 없이 연구 runner만 추가됐다. 빌드 산출물은 프로젝트 `target/`이다.

```toml

name = "strategy-review-runner"
version = "0.1.0"

[dependencies]
kis-auto-trade = { path = "../../../src-tauri" }
serde_json = "=1.0.149"
[[bin]]
name = "strategy-review-runner"
path = "../../../docs/research/strategy-review-20261018/runner.rs"
[[bin]]
name = "soxq-frozen-review-runner"
path = "../../../docs/research/soxq-3m-20261003/runner.rs"
```

처음 cache manifest/lock을 구성할 때 `cargo check --offline --manifest-path ...`로 runner 항목을 추가한 뒤 이하에서는 `--locked`를 사용한다. 입력 재생에는 보관한 `input.json`만 필요하다. `prepare_data.py`는 원본 cache의 4개 공개 다운로드가 있을 때 입력 정규화 과정을 재현한다.

```bash
cargo run --offline --locked --manifest-path .cache/research/strategy-review-20261018/Cargo.toml --bin strategy-review-runner -- docs/research/strategy-review-20261018/input.json .cache/research/strategy-review-20261018/full-results.jsonl
TZ=America/New_York target/debug/strategy-review-runner docs/research/strategy-review-20261018/input.json .cache/research/strategy-review-20261018/repeat-results.jsonl
```
