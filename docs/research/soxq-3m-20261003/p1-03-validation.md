# SOXQ-P1-03 일봉 날짜/완료봉 검증 (2026-10-03)

엔진 `strategy-replay-v5`. 동결 SOXQ 입력의 평가 64봉(2026-07-06~10-02)과 기존 비용·리스크 가정을 유지했다. 사전자료 252봉 모드와 사전자료 없는 진단 모드를 각각 실행했다. `ui_three_month_defaults`는 이전 runner의 이름이며 현재 UI provider 조회를 그대로 재현한 모드가 아니다.

[기본 결과](p1-03-results.json), [각 20bp 비용 스트레스](p1-03-cost20-results.json), [이전 v4 결과](p1-01-validation.md), [작업 기록](../../../tasks/appledouble-and-soxq-p1-03.md). 초기 v2 차트/보고서는 당시 관측으로 보존한다.

## 이벤트와 포지션 경계

1. 날짜 시작에는 시가만 전달한다. 날짜 전환에 전략 `reset()`을 호출하지 않는다.
2. 해당 봉 종가 시점에 완성 OHLC를 공개한다. 강한 종가는 이전 완료일 조건을 사용하고, 변동성 확장은 당일 high-low 및 시가 대비 방향을 **이전 N개 완료일** 평균 범위와 비교한다.
3. raw 신호를 비용·리스크 backtest로 처리한 뒤 실제 체결/차단 결과의 보유 수량·평균가를 전략에 되먹임한다.
4. 그 뒤 완료봉을 적재한다. 강한 종가는 다음 평가일 조건을 새로 준비하고 변동성 확장은 bounded range ring을 갱신한다. 유효한 flat-day 0범위도 일수에 포함한다.

이 순서는 차단된 매수의 낙관적 내부 포지션 때문에 다음 날 강한 종가 pending이 사라지는 문제를 막는다. 신규 일자에는 변동성 전략의 당일 고저가만 초기화하며 실제 보유와 이전 범위는 유지한다. 완료 OHLC를 장 시작 판단에 노출하지 않는다.

두 전략의 generic replay는 `D`/`1d`만 지원한다. 분/주/월봉은 `UNSUPPORTED_REPLAY_INTERVAL`로 거부하고 UI도 일봉 선택만 제공한다. 일봉 cadence는 `dailyCloseWithDayBoundary`이며 기존 평가/사전자료·준비 상태 계약을 유지한다. 기본 event 훅은 다른 전략에서 기존 tick으로 위임하거나 no-op이다.

이벤트는 generic 과거 일봉 replay에 연결했다. 현재가만 공급하는 live polling과 전용 LTH 경로는 기존 경계를 유지한다. live 날짜/완료봉 공급 또는 실제 broker 거래를 검증한 작업이 아니다.

## 같은 입력의 결과

아래는 사전자료 252봉 모드다. 이번 두 전략은 사전자료 없는 모드에서도 같은 신호/체결/계좌 결과를 보였지만 조건 평가 가능 봉 수는 다르다.

| 전략 | v4 각10bp 수익률 | v5 각10bp | v5 각20bp | MDD(10bp) | 완료 거래 | 체결 주문 | 첫 매수 |
|---|---:|---:|---:|---:|---:|---:|---|
| 강한 종가 | +0.0000% | +1.7179% | +1.5871% | 2.0740% | 2 | 5 | 2026-07-07 |
| 변동성 확장 | -0.0300% | +0.7807% | +0.7523% | 0.2531% | 0 | 1 | 2026-09-21 |

강한 종가는 완료 거래 2회 모두 손실이며 기말 10주를 보유한다. 양의 계좌 수익률은 미실현 손익도 포함한다. 변동성 확장은 완료 거래가 없고 기말 10주 보유다. 이 수치로 전략 우수성·완료 승률을 판정하지 않는다. v4의 변동성 마지막 날 매수는 3개월 종가를 누적한 범위 모델에 따른 관측이었다.

| 사전자료 없는 진단 | 시작 준비 | 첫 준비 시각(봉 처리 후) | 조건 평가 봉 | 처리 후 미준비 봉 |
|---|---|---|---:|---:|
| 강한 종가 | 미준비 | 2026-07-06 | 63 | 0 |
| 변동성 확장(10일) | 미준비 | 2026-07-17 | 54 | 9 |

첫 준비 시각은 완료봉 적재 후 상태다. 강한 종가 첫날과 변동성 10번째 날은 다음 평가일을 준비하며 그날 조건 평가로 세지 않는다. 사전자료 252봉 모드에서는 두 전략 모두 처음부터 준비되어 64봉을 평가한다. 기본 lookback을 줄이지 않고 평가 중 확보한 완료일만 사용한다.

수수료·슬리피지 각각 10/20bp, 거래세 0, 환율 1450원, 초기자본 1천만원, 주문 10주와 기존 guard를 유지했다. 배당·환율 변화·기말 강제청산은 제외한다. 강한 종가의 다음 평가일 신호도 **그날 종가**에 체결하는 근사이며 익일 시가 체결은 아니다. 장중 손절 도달/가격 경로도 복원하지 않는다. next-open(P2-14), true-range ATR(P2-16), LTH 시각/분봉(P1-04/05), provider 이전 자료 페이지(P2-17)는 남아 있다.

## 재현과 검증

- 모든 26개 generic 실행은 같은 평가 시작/종료와 64봉을 유지한다. 사전자료 모드는 252봉, 없는 모드는 0봉이다.
- `generatedAt`만 제외한 지원 전략 24개 실행(12전략×2모드)의 신호·메타데이터·준비·backtest가 동일 입력 재실행과 완전히 일치한다. generic LTH는 비결정적/준비 미지원 진단이므로 재현성 주장에 포함하지 않는다.
- 변경 대상 두 전략과 LTH를 제외한 20개 실행은 v4와 candles·raw 신호·준비 상태·backtest가 일치한다. 전역 engine/cadence/input hash 변경은 의도된 메타데이터 차이다.
- 날짜별 독립 조건, 미래 봉 변경의 이전 신호 불변, 차단 매수 피드백, 보유/손절 유지, 현재 범위의 이전 평균 혼입 방지, flat-day 0범위와 bounded window, 평가 중 준비, 비일봉 거부를 fixture로 검증했다.
- Rust 전체 lib **180 PASS**, focused UI **22 PASS**. 전체 target check, all-features Clippy, rustfmt, TypeScript/FSD/lockfile, web build 통과. 최종 문서/프로젝트 맵/그래프와 도구 진단은 작업 기록에 기록한다.
- Serena 영향 추적과 독립 코드 리뷰 완료. 리뷰에서 미수정 결함은 발견하지 않았다.
