# P2-06 연속 가격 관측 진입 필터 연구

생산 실행과 55,986개 독립 기록 산술 대사를 통과했다. 독립 전담 감사도 별도 스크립트로 312개 원장·148,099개 검사를 수행해 오류0을 확인했다. 최대 차이는 약0.01원/0.00005%p로 출력 반올림 범위다. 최종 통합 게이트는 작업 기록에서 확인한다. 후보는 모두 선택 기능이며 기본값에 자동 채택하지 않았다.

## 사전 고정 설계

생산 Rust 라이브러리를 호출하며 별도 매매 모형을 구현하지 않는다. [설계](design.json)의 SOXQ 51주·SPY 2주·QQQ 3주와 기존 매수/매도 3/3 관측을 고정한다. 평가 자료는 2023-01-03~2025-12-31의 각 752개 일봉, 이전 완료 자료는 별도 252개다. 동결 원본은 [기존 전수 연구 입력](../strategy-review-20261018/input.json), SHA-256은 `d48ce5b59b7876c0a1457121e877fdc1117a77f990b4ec07ce649c92fe153317`이다.

기본 비활성, 누적 변화 1%, ATR 0.5배, 완료 종가 MA 200을 각각 단독 비교한다. 후보 실행 전에 설계를 기록했으며 조합·최적 임계값 탐색을 하지 않는다. 누적 변화와 ATR은 이상, MA는 엄격히 큼이다. ATR은 직전 완료 실제 OHLC15개의 TR14 산술 평균이고 0이면 신규 진입을 보류한다. 현재 평가 봉은 후보 판단 뒤에만 완료 자료로 적재한다.

초기 자본 1천만원·고정 FX1450·수수료/슬리피지 각각10/20bp·세금0·무배당·다음 관측 시가 체결·보호 overlay0·기존 공통 주문 guard/risk를 유지한다. 같은 최초 요청 수량이 실제 노출을 같게 만들지는 않는다. 12분기 묶음을 하나의 장부로 실행한 24회와 500+252 두 묶음의 24회를 대조한다. 별도 분기 초기화 288회는 매번 독립 현금 계좌이며 수익률을 합산·복리하지 않는다.

## 기본 호환과 단위 문구

기준 커밋 `6f9ca35`의 독립 Git archive 생산 라이브러리로 단기 1,224회(Consecutive 102회 포함)와 장기 6회 기준을 생성한다. 전체 backtest와 signals를 canonical JSON으로 비교한다. 유일한 문구 예외는 Consecutive의 reason 키에서 정확한 숫자+`일 연속 상승 → 매수`/`일 연속 하락 → 매도`를 관측 단위로 바꾸는 것이다. 숫자·side·다른 필드·임의 추가 설명은 정규화하지 않으며 치환 횟수를 보관한다. 최초 장기 대조는 SPY20 마지막 미체결 reason의 알려진 종료 suffix 때문에 실패했다. 독립 원문 비교에서 회계·경로 차이는 없고 한 reason만 다름을 확인해, 정확한 종료 suffix ` · 평가 종료: 다음 관측 봉이 없어 미체결`는 원문 보존한 채 앞의 두 단위 템플릿만 교정하도록 대조기를 보완했다.

## 재현과 독립 대사

- [baseline_runner.rs](baseline_runner.rs): 변경 전 생산 라이브러리의 [단기 기준](baseline-hashes.json)과 [장기 기준](long-baseline-hashes.json).
- [runner.rs](runner.rs): 변경 후 생산 라이브러리의 실제 전략·체결 피드백·장부 실행. 프로젝트 `.cache/`의 임시 Cargo manifest에서 저장소 `src-tauri`를 path dependency로 지정한다.
- [validate.py](validate.py): 기록된 실제 체결만 독립 산술 대사. 신호를 재생성하지 않는다. 검증 완료 후 JSONL 전체를 무손실 gzip으로 보관하고 평문은 `.cache/consecutive-research-output/`에 둔다.

검증은 현금·체결 가격·수수료·슬리피지·실현/잔여 원가·기말 가상 청산·MDD·회전·실제 노출을 대사한다. 실제 전봉 보유 수량의 close→open 갭과 accepted open 이후 수량의 open→close 손익을 나눠 비용 복원 참조와 비교한다. 이 참조는 동일 수량/보유 경로의 산술이며 독립 알파 benchmark나 무비용 전략 재실행이 아니다. 진입후보·자료 부족·필터 거절·통과와 공통 guard/risk의 후속 차단을 분리한다.

## 해석 한계

이미 관측한 상관 ETF 3개의 사후 진단이다. 사용하지 않은 2026을 독립 OOS 증거라고 주장하지 않는다. 거래소 달력·가격 조정·coverage와 실제 장중 체결·quote 간격은 별도 검증이다. 낮은 MDD/회전이 낮은 노출이나 현금 보유 때문인지 함께 읽고 작은 청산 표본·필터 거절로 생긴 0거래를 우수성으로 해석하지 않는다. 어떤 후보도 live 기본 설정에 자동 채택하지 않는다.


## 결과와 기각 근거

[전체 312개 계좌 요약](summary.csv) · [24개 연속/별도 분기 분포](aggregate.json) · [실행·분할 대조](run-summary.json) · [독립 산술/파일 해시](validation.json). 실제 연속 장부24개와 별도 분기288개를 보관했고 대체 분할24개는 같은 경제 hash·input hash임을 확인했다. 기본값은 단기1,224개와 장기6개 모두 전체 backtest/signals가 일치한다. 기준 단위 치환 건수는 파일별 normalizedReportReasons/normalizedSignalReasons와 validation에 기록되어 있다. 최상위 generatedAt은 실행 시각이므로 재실행 시 아카이브 byte hash는 달라질 수 있다. 경제/입력 hash와 report/signals의 동등성은 별도로 확인한다.

- **MA200은 수익 개선 공통 후보로 기각하고 노출 감소 효과로 구분한다.** 모든 ETF×두 비용의 순수익이 낮아졌다. SPY/QQQ의 MDD는 줄지만 평균 투자도 감소한다. SOXQ는 순수익과 MDD가 함께 나빠졌고, 20bp 최악 청산 손실은 3ETF 모두 줄지 않았다. 낮은 회전/MDD만으로 기본 채택하지 않는다.

### 후보·후속 차단과 준비

활성 단독 후보18개 연속 장부와216개 분기 계좌는 모두 준비된 실제 이전 일봉을 사용했고 unreadyCandidates=0이다. 각 단독 후보의 candidates=필터 거절+passedCandidates, passedCandidates=raw 매수 신호 수를 독립 확인했다. 복수 필터의 거절 수는 중복될 수 있으나 이번 연구는 단독만 실행했다. 모든0 기본에서는 optional 진단을 생략하므로 baseline의 후보 수를0으로 채우지 않는다. 기본 raw 매수 수는 보관 signals로 확인할 수 있다.

20bp에서 SOXQ의 누적1/ATR0.5/MA200은 후보52/52/63, 필터 거절1/2/9, 후속 주문 차단32/32/37건이다(기본 차단33). SPY는30/29/38 후보 중1/0/10거절, 후속 차단6/5/5건이다(기본5). QQQ는27/25/31 후보 중2/1/9거절, 후속 차단3/4/4건이다(기본4). 필터 통과는 실제 체결과 다르며 guard를 완화하지 않았다. 필터로 진입이 달라지면 보유/청산/다음 후보/비중 차단도 달라진다.

기본 SPY 비용별 실제 경로는 회귀와 연구에서 보존했다. 10bp의2023-08-04/2025-02-25 매도가20bp에서는2023-08-07/2025-03-31로 바뀐다. 후자의 공통 기대 순익 gate와 실제 손익 변화를 유지했으며 필터 결과를 좋아 보이게 만들기 위해 청산 방어를 풀지 않았다.

### 별도 분기 계좌와 노출

각 후보·종목·비용에12개의 초기화 계좌가 있다. 대부분 분기의 신호가 같아 중앙값이 변하지 않는 경우를 구분한다. 예를 들어 SOXQ20bp 기본/ATR0.5의 별도 분기 중앙값은 모두 +0.31885%이고 최악도 −1.2984%지만 최대 분기는 +6.0603→+6.4451%다. 연속 순수익의 개선을 모든 분기의 일관된 개선으로 표현하지 않는다. QQQ20bp MA200은 최악 분기 −2.0963→−1.2108%지만 중앙값 +0.8079→+0.60975%, 연속 순수익도 낮아진다.

최종 결정은 기본 필터0 유지다. 생산 기능과 사전 고정 단독 A/B·기각 근거를 완료한 것이며 실제 운용 효과·실거래 안전성·수익 우월성을 확정한 것은 아니다. 필터 조합이나 사후 최적 임계값 선정은 수행하지 않았다.
