## 이번에 확인한 구현

기준81fa00d의 TrendFilter는200/5/20 현재 관측 포함 산술평균이다. 실제 원래 청산은 보유 중price < longMA, 진입은 미보유에서price > longMA AND shortMA > midMA다. strict 경계와 별도 원가 손절 부재를 유지한다. 원래 구현이 제안 신호로 보유bool을 바꾸고 실제 수량·평균을 버리는 점과 선택 청산 정책의 효과를 구분할 예정이다.

소스의 bool-only 상태·설정 수량 제안만으로 실제 초과매도·사고나 기존 손실 원인을 단정하지 않는다. live bool 복원/driver sync·공통 수량 clamp/guard가 존재하며 owned 교정의 경제 효과는 동일 입력 생산 비교 전까지 미확인이다. 원래 MA 청산은 세 MA 준비 gate를 유지하고 새 수익/나이 보호만 이 gate와 독립 평가한다.

실제 소유 대조와 장기 이탈 확인2·수익5/되밀림3·보유63의 단독 후보를 고정했다. 기본 확인1과200/5/20을 유지한다. 확인 횟수는 영속 복원 시0이며 실제 소유 나이/최고가/무장과 분리한다. 자세한 상태·시점·미체결 계약은protocol.md가 정한다.
