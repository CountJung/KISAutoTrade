# SOXQ-P2-11 생산 결과 독립 감사

2026-10-25. [독립 감사 코드](independent-audit.py)로 [정산 결과](independent-audit.json)의 **390개 원장·171,604개 검사·오류0**을 확인했다. 감사는 부모가 실행한 생산 Rust 결과의 체결 산술과 해석만 수행했다. 별도 신호 모델·Rust 재실행·provider/계좌/주문 호출은 하지 않았다. 연구 정산에서 수정이 필요한 불일치는 발견하지 않았다. 소프트웨어/UI·통합 검증과 P2-11 최종 완료 판정은 부모의 별도 게이트다.

## 입력·실행 증거

- [설계](design.json) SHA256 `f2a3f801da05d77544580b3fabc265197bdc26cd7072859df9f2f4428262040f`, [동결 입력](../strategy-review-20261018/input.json) SHA256 `d48ce5b59b7876c0a1457121e877fdc1117a77f990b4ec07ce649c92fe153317`를 독립 대조했다.
- SOXQ/SPY/QQQ, 평가2023-01-03~2025-12-31 각752일봉, 이전252봉이다. 일봉 날짜는 입력의 America/New_York 거래소 날짜다. 수량51/2/3주, 최초 기준일2022-12-30, 초기자본1천만원, 고정FX1450원, 배당/세금/연구 stop/take-profit0을 유지했다.
- 비용10/20bp는 **각 방향 fee와 slippage가 각각10/20bp**다. 개략 왕복40/80bp이며 왕복10/20bp가 아니다. idle cash는 KRW이며 실제 브로커 USD현금 장부를 재현한 결과가 아니다.
- [기준 실행기](baseline_runner.rs)는 `81fa00d3aa50bc59606667568f36c4b686902412`/v21, [현재 실행기](runner.rs)는 시작HEAD70df3b3 이후 구현/v22의 생산 preview API를 호출했다. [기준 소스 검증](baseline-source-validation.json)에 기록한7개 파일 SHA를 Git object bytes와 다시 대조했다. 두 path harness는 사용 가능한 호환 의존성을 별도 해석했으므로 **동일 Cargo.lock으로 빌드했다고 주장하지 않는다**.
- 연속30개·별도 분기360개의 유일한 설계 조합, 모든252봉 warmup·준비 완료·비용/수량/설정·평가봉을 확인했다. [실행 요약](run-summary.json)의 대체분할30개/inputHash 대응을 확인했으며, 대체분할 전체 원장의 equality는 부모 Rust 실행기의 검사 기록이다. 감사자가 이를 별도로 재실행한 것은 아니다.
- 입력의 source URL·조회일·raw/normalized hash·조정 한계를 승계한다. 원본 raw bytes·기업행사·배당 조정·거래소 달력 coverage·feed completeness는 이번 감사에서 인증하지 않았다. 이미 본 상관3ETF 과거 자료와 겹침 분기는 독립 OOS가 아니다.

## 기존 할일에 연결할 후속 조치

1. **SOXQ-P2-11, 현재 완료 게이트:** 부모가200/5/20·실소유·엄격 설정/복원·두 preview/UI·전체 검증·문서 게이트와 이 독립 정산을 함께 기록한다. 위험은 유리한 후보만 기본 승격하거나 교정과 정책 효과를 혼합하는 것이다. 완료 기준은 고정5후보의 실제 청산·비용/노출·실현/잔여를 재현 가능하게 보관하고 기본 확인1/선택0을 유지하는 것이다. 이 보고서는 유효성 검증 완료를 대신하지 않는다.
2. **SOXQ-P2-16, 표본·walk-forward 후속:** 후보를 기본으로 승격하려면 새 자료를 읽기 전 창·수량·가설·비용·선택 기준을 고정한다. 의존성은 검증된 가격/조정/coverage와 충분한 실제 청산 표본이다. 완료 기준은 새 표본에서 동일 비용·실제 체결 노출·실현/잔여·MDD·차단/회전을 독립 대조하고 미발동을 미평가로 남기는 것이다. 현재 QQQ 확인2의 완료1건이나 상관3ETF의 겹침 분기는 이를 충족하지 않는다. 이번 P2-11을 새 자료 확보 전까지 무조건 열어둘 요건으로 추가하지 않는다.

감사 입력은 `.jsonl` 또는 같은 bytes의 `.jsonl.gz`를 지원한다. 압축 해제한 두 원장 SHA는 `independent-audit.json`에 기록했다. 코드와 JSON을 다시 실행해 같은 결과를 재생성할 수 있다.
