## 자료와 실행 계약

[기존 동결 자료](../strategy-review-20261018/input.json)의 SHA256은 `d48ce5b59b7876c0a1457121e877fdc1117a77f990b4ec07ce649c92fe153317`이다. 2021-12-31~2022-12-30 이전252봉, 2023-01-03~2025-12-31 평가752봉과 SOXQ/SPY/QQQ의 최초 수량51/2/3주를 고정했다. 초기자본1천만원·FX1450·nextOpen·fee/slippage 각각10/20bps·tax0·배당/FX/연구 overlay 비활성을 유지한다. 실제 계좌·provider·주문·운영 DB·민감 파일에 접속하지 않는다.

기본3%는 이전 완료 고가 대비 종가 거리 `(H-C)/H*100<=3`이며 양봉·상승률 조건이 아니다. 평탄봉도 통과한다. 기존 stop3을 보존하며 stop0은 비활성이 아니라 평균가 이하 청산이다. 일봉 replay는 D-1 완료봉 조건→D종가 신호→D+1 관측 시가 체결이고 실시간 첫 eligible quote와 다르다. P1-03의 완료 뒤 게시 순서를 유지한다.

## 정확성과 UI

실제 소유 수량·평균가·잔량으로 청산하고 체결 전 제안으로 소유를 만들지 않는다. 실제 첫 체결의 나이는0, 이후 보유 관측부터 증가하며 같은 수량·부분 체결·설정 변경 시 보존한다. 출처 미상은 미상으로 유지하고 한도가 활성화되면 보수적 청산 후보를 제공한다. 물리 pending 상태의 억제된 새 신호로 진입 증거를 만들지 않으며 기존 증거는 유지한다. 수익 보호는 실제 보유 관측의 최고가만 사용한다. 새로운 version1/kind strongClose 메타데이터는 누락·다른 kind·모순·미지 필드를 원자적으로 거부한다.

UI는 이전 완료 일봉 추세·수익 보호 시작/되밀림 쌍·보유 관측 수를 기본0으로 제공한다. null·문자열·bool·NaN·정수 위반·불완전 보호 쌍은 저장과 단기/연속 preview가 함께 거부한다. 현재/A-B는 params·완료 자료 준비·진입 후보/거부를 표시하고 과거 엔진/응답 정보는 미확인으로 둔다. 저장 실패·지연 응답·새 초안·취소·좁은 화면을 mock으로 검증했다.

이번 연구는 이미 본 상관된 ETF3개와 고정 가격·고정 환율을 사용한 사후 비교다. 별도 미관측 기간·분봉 live 체결·거래소 달력 완전성·가격 조정·기업행위·실계좌 비용·호가 유동성·배당·환전·실제 공급 자료의 시점은 검증하지 않았다. 새날 공급 경로는 합성 ticket/자료 fixture다. 실제 또는 모의 주문·자동매매·계좌/운영 DB 접근은 하지 않았다. 후보 수치를 다시 조정하거나 조합하지 않았고 선택값은 모두 비활성을 유지한다. 후속 승격은 별도 미관측 자료와 비용·노출이 맞는 반복 비교, 원본 일봉·시간대·시장일 검증, 모의 운용·주문/체결 대조의 기존 운영 게이트를 충족해야 한다.
