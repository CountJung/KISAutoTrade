# P2-04 이격도: 실제 소유와 단독 진입·청산 후보

생산 실행과 기록 대사를 완료했다. 후보를 운용 기본값으로 선택한 보고서가 아니다.

## 사전 고정과 재현

[사전 선언](design.json), [archived 실행기](baseline_runner.rs), [현재 생산 실행기](runner.rs), [독립 기록 산술](validate.py)을 보관한다. 입력은 [동결 공개 가격](../strategy-review-20261018/input.json)이며 SHA-256은 `d48ce5b59b7876c0a1457121e877fdc1117a77f990b4ec07ce649c92fe153317`다. 계좌/전략 운용 설정을 읽거나 변경하지 않았다.

기준은 `bca6601`의 실제 Rust 생산 라이브러리(v14), 후보는 같은 production preview를 사용하는 v15다. Python은 기록된 체결/현금/노출을 대사할 뿐 전략 신호를 다시 구현하지 않는다. 12전략×각102개의 단기 입력에서 비이격도1,122개 전체 report/signals 호환과 이격도102개 차이를 구분한다. 별도 연구는 SOXQ/SPY/QQQ, strict252준비(2021-12-31~2022-12-30)와2023-01-03~2025-12-31의752봉이다. 고정 최초 수량51/2/3, 현금1천만원, FX1450, 세금0/배당·FX시나리오없음, nextOpen, 수수료·슬리피지 각각10/20bp를 사용한다. 기존 guard/risk와 maxPositionRatio0.3, replay 손절/익절 overlay0은 유지한다.

3년 상태를 보존하는 분기12청크와500+252청크를 비교한다. 분기마다 재시작하는12개 계좌는 각각 새1천만원이며 합산·복리하지 않는다. 기존 전수 연구의2023Q1~2026Q3분포와 이번2023~2025연속/분기 결과를 합치지 않는다.

후보를 결합하거나 사후 임계값을 최적화하지 않는다. 기본은 corrected level과 다른옵션0이다. 기존 현재 포함 MA20/Buy<=−5/Sell>=+5를 유지한다. 교차 후보는 조건 유지 중 미체결 재시도, 임계값 상회 취소, 실제 양수 체결 후 소비한다. 손절→관측 한도→고이격 순서이며 보호 exit는 잔량 전량 요청, 기존 고이격은 설정 수량을 유지한다.

실시간 장기 추세는 첫 live tick에서 별도 버퍼를 비우고 실제 관측으로 준비한다. 일봉/1분 warmup을10초 관측으로 간주하지 않는다. 보유 관측은 옵션off 중에도 기록하고 같은수량/partial/warmup/설정 변경으로 줄이지 않는다. 유효 exact owner 나이 metadata 없이 복원한 보유는 unknown이며 활성 관측 한도는 다음 관측에 보수적 매도 후보를 낸다. 이 연구의 maxHold63은 일봉종가63관측이고 live63일이 아니다. stop5 역시 관측 신호 뒤 다음 시가·갭·비용을 거치므로5% 손실 상한이 아니다.

재현할 때 저장소 안 `.cache/`에 archived commit과 Cargo harness를 만들고 두 Rust 실행기를 해당 library path에 연결한다. `.cache/deviation-head-baseline-harness/Cargo.toml`의 dependency는 archived `bca6601/src-tauri`, current harness는 루트 `src-tauri`다. 기본1224/연속6/분할6/분기72 기준 산출물을 먼저 만든 뒤 현재1122호환/102delta와30연속/30분할/360분기를 실행한다. 실행기 argv는 저장소 절대 경로다. `python3 docs/research/deviation-policy-20261020/validate.py`는 gzip을 보존하고 평문 JSONL을 ignored cache로 이동한다. 생성 시각이 포함되어 실제 재실행 gzip SHA는 달라질 수 있으므로 최종 input/source/기록 hash와 구분한다.

### 단독 후보의 기각·보류 근거

- **crossing:** 연속6개 경제 경로가 기본과 같다. 비용별36개 분기 중1개 개선·35개 동일이다. SOXQ2025Q2의20bp는−0.4170→+2.2633%, MDD4.3615→2.7142%이며 청산1회로 작다. 연속 상태와 분기 초기화 효과가 다르므로 공통 우수성을 확정하지 않는다.
- **trend200:** SOXQ20bp 수익4.5454→8.0412%와 MDD9.1305→4.4717%는 평균투자7.4141→4.0528%·청산7→5·회전362.9716→250.7242%를 동반한다. SPY/QQQ 연속은 추가효과가 없다. 비용별 분기는3개 개선·4개 악화·29개 동일이며 변경된7개 계좌 모두 신규 거래를 하지 않은 결과다. SOXQ2025Q1의−3.7377→0% 회피와2023Q4의+1.8976→0%, SPY2025Q2의+2.0060→0% 누락이 함께 존재한다. 낮은 노출·무거래를 시장 전반의 우수한 진입으로 확대하지 않는다.
- **maxHold63:** 연속 SPY/QQQ의 경로를 바꾸지만 독립 분기72개는 모두 기본과 같다. 짧은 초기화 계좌는 보유63관측에 도달하지 않아 효과 검증을 대신하지 못한다. SOXQ는 실제 경제 경로가 같고 두 비용에서 filled reason만 고이격→보유64관측으로 바뀐다.2023-11-09 종가의 관측63 신호는11-10 시가의 기대순익 guard에 막혔다.11-10 종가의 관측64 신호는11-13 시가에 기존 고이격 청산과 같은 가격·수량으로 체결됐다. 관측 한도를 강제 청산 날짜로 표현할 수 없다.
- **stop5:** SOXQ20bp 수익4.5454→2.6040%, MDD9.1305→9.5692%, 청산7→14, 회전362.9716→700.4214%다. 최소 청산손익도−444,109.90→−480,262.71원으로 악화했다. SPY/QQQ 연속은 추가효과가 없고 분기는 비용별2개 개선·5개 악화·29개 동일이다. SOXQ2025Q1은−3.7377→−5.0846%, 완료0→2회·실현−370,795.48원/잔여−137,666.91원으로 나빠졌다.5% 관측 손절은 손익5% 한도가 아니다.

SPY maxHold63의 순수익은 **10bp1.4705%보다20bp1.9441%가 높다.** 비용이 이득을 만든 회계 오류가 아니라 기존 net-exit guard가 실제 경로를 바꾼 결과다.2025-05-02 종가 신호를 받은10bp는05-05 시가에 청산해2,685.58원을 실현했지만20bp는 같은 시가에 기대순익0이하로 차단됐다.20bp는05-12 종가 신호 뒤05-13 시가에 청산해56,372.68원을 실현했다. 높은 비용의 효과를 같은 경로 비용 차감으로만 설명하면 틀린다.

기본은 실제 소유 교정 level/다른옵션0을 유지한다. 네 후보를 결합하거나 공통 운용 기본값으로 승격하지 않았다. 선택 옵션 구현·과거 진단과 실제 운용 채택 판단은 구분한다.

### 검증 범위

최종 원장468개에서 부모의 기록 산술68,421개가 통과했다. 회계·원가·실현/잔여·수수료·슬리피지·매 봉 equity/MDD·회전/노출·기말 비용·직전 종가→시가/시가→종가의 실제 수량 경로를 각각 대사했다. 생산신호를 Python에서 다시 만들지 않았다. 대체36분할은 생산 runner가 동일 engine의 전체 backtest/signals/preparation·입력 hash를 비교한 결과다.

경제 경로 동일성은 account/equity와 실제 filled 기록의 모든 필드를 비교하되 **reason 문자열만 제외**한다. 원본 filled 기록 전체의 동일성은 별도 CSV 필드로 보존한다. 이 구분은 SOXQ maxHold의 동일 시가/수량/비용에서 청산 사유만 바뀐 경우를 드러내며 원장을 정규화하거나 숨기지 않는다. source/실행기/생산 코드 SHA와 압축 전 SHA는 validation에 보관한다. 독립 stock 감사는 원장468개199,065 + flat102개1,430 = 총200,495검사에서 오류0을 확인했다. 최대 차이는 약0.010000004원/0.000050022%p의 출력 반올림 범위다. 독립 감사는36개 분할 hash 대응을 확인했으며 대체 분할 payload를 별도 재실행한 것으로 집계하지 않는다. core의 actual owner/native avg/관측 나이 unknown·부분체결·재시도·live trend 분리·metadata 복원/관측 뒤 저장 실패 차단도 읽기 전용으로 감사했다.


## 한계

이미 확인한 가격으로 수행한 사후 진단이며 독립 OOS나 통계적 우월성 증거가 아니다.2026봉을 사용하지 않았다는 사실만으로 사전 미관측 검증이라고 부르지 않는다. 선택된 상관ETF3개와 작은 완료 청산 표본, 고정환율/무배당·거래소 달력/기업행사 coverage 미인증의 한계가 있다. 동일 최초 수량은 동일 실제 투자 비중이 아니다. 평균/최대 노출은 봉말 관측이며 장중 최대가 아니다.

같은 실제 체결 수량/시각의 비용 환급 reference는 별도 전략이나 비용0으로 다시 신호를 실행한 결과가 아니다. 무거래·낮은 MDD·낮은 투자 비중·미청산 평가이익을 전략 우수성으로 해석하지 않는다. 기록된 공개 가격 replay와 합성/mock 계약 검증은 실제 broker 주문·계좌 귀속·장중 체결·실운용 검증을 대신하지 않는다.
