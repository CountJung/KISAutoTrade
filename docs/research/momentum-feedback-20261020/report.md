# P2-03 모멘텀 소유 피드백과 진입 교차 비교

기본 level의 보유 상태를 교정해 무보유 매도·보유 중 매수를 없앴다. 고정 자료에서 실제 체결·원가·현금·평가 경로는 유지되며 raw 신호와 후속 차단만 줄었다. 선택 crossing/1%p 재무장 간격은 일부 분기 초기화 계좌의 경로를 바꾸지만 추가 수익 개선의 공통 근거가 없어 기본 level/간격0을 유지한다. 외부 운용 검증이나 우수 전략 확정이 아니다.

## 사전 고정 조건과 원인

[설계](design.json)는 후보 실행 전에 고정했다. 기준은 Git archive의 생산 라이브러리86a9829, 수정 후는 공통 replay v14다. 기존 classic.rs negative branch에는 실제 보유 검사가 없고 모든 sync_position 피드백이 last_sell_price를 지웠다. live 후보의 anchor 복원도 억제 상태를 유지하지 못했다. 새 구현은 exact owner 수량을 raw 관측과 분리한다. 기존 guard/risk는 유지했다.

사전 소스 감사가 초기 strict 경계 가정을 바로잡았다. 기존 매수>=T/매도<=−T를 유지하고 소유 교정과 경계 변경을 섞지 않았다. source가격은 [동결 입력](../strategy-review-20261018/input.json), SHA256 `d48ce5b59b7876c0a1457121e877fdc1117a77f990b4ec07ce649c92fe153317`이다. SOXQ/SPY/QQQ 각2023-01-03~2025-12-31의752개 일봉과 이전252봉을 구분한다. 수량은 최초51/2/3주, 기간20/임계값5 고정이다.

초기자본1천만원·고정FX1450·다음관측시가·수수료와슬리피지각10/20bp·세금0·무배당·overlay0·기존 최대비중/공통guard/risk를 유지한다. live설정·계좌자료·주문을 사용하지 않는다. 관측 간격이 다른 live/replay 효과를 같은 것으로 주장하지 않는다.

| 후보 | 생산 실행과 의미 |
|---|---|
| legacy | 이전86a9829 라이브러리. 새 live 옵션으로 남기지 않음 |
| confirmedLevel | 현재 생산 코드 기본. 실제0수량에서매수/양수에서매도,기존inclusive level 유지 |
| crossing | 이전m<T→현재m>=T 신규진입, 간격0. 보유negativelevel청산유지 |
| hysteresis1pp | 같은crossing과 m<=T−1 재무장. T5에서는<=4, 상대1%/4.95%가아님 |

cross 후보는 m<T에서 취소하고 m<=T−간격에서만 재무장한다. 미체결 후보는 m>=T동안 재시도할 수 있으며 같은0수량/nextOpen pending으로 성공 처리하지 않는다. 실제양수 소유량으로 소모하고 부분매도후양수보유는level청산을계속평가한다. strict warmup은 이전m/무장만 seed하고 가상후보·체결을 만들지 않는다. level에서유효간격draft를보관하되미사용을명시한다.

## 실행과 독립 기록 대사

[기준 실행기](baseline_runner.rs)는 archived flat1224/연속6/대체분할6/별도분기72를 실행했다. [현재 실행기](runner.rs)는 비모멘텀1122개 전체 backtest/signals exact호환, [모멘텀102창 변화](flat-momentum-deltas.json), 새후보 연속18/대체분할18/분기216을 실행했다. 합계24개연속·24개분할대조·288개별도분기이며 분기계좌를 합산/복리하지 않는다. [실행기록](run-summary.json)·[기준기록](baseline-run-summary.json)을 함께 보관한다.

[정산 검증기](validate.py)는 기록된 실제 accepted fill을 사용해 현금·원가·fee/slip·각봉자산·MDD·회전·실현/잔여·노출·기말가상청산과 실제수량의 gap+장중손익/비용복원 참조를 46,772개 항목으로 대사했다. 별도 전담 감사는 원장312개 135,530검사와 단기102개 1,430검사, 합계136,960검사 오류0을 확인했다. 최대 금액 차이는 약0.01원, 지표 차이는 약0.00005003%p로 출력 반올림 범위다. 전략 신호를 다른모형으로 재생성하지 않는다. [해시/검증](validation.json), [312개계좌요약](summary.csv), [분기분포](aggregate.json)를 참조한다. 원문 전체는 [연속gzip](continuous-results.jsonl.gz)과 [분기gzip](reset-results.jsonl.gz)에 무손실 보관하고 평문은 프로젝트.cache에 둔다. generatedAt은 실행시각이므로 재실행 시 전체bytehash가 달라질 수 있으며 경제/입력hash와별도로검증한다.

## 교차·재무장 간격의 채택/기각

세현재후보의연속6개경제장부는모두같다. 따라서이3년자료에서 crossing/hysteresis의추가성과개선을관측하지못했다. 별도초기화분기에서는crossing72개중10개,hysteresis12개의경제경로가달랐다. 초기 warmup의 이전 모멘텀/무장과 진입 지연 차이를 연속 운용 효과와 섞지 않는다. 비용별36개 분기에서 crossing은2개 개선/3개 악화/31개 동일, hysteresis는2개 개선/4개 악화/30개 동일이었다.

- SOXQ2023Q2 crossing은10/20bp수익+0.8447/+0.7355→+1.3041/+1.1958%,MDD와평균투자감소였다. 하지만2024Q1은+5.3743/+5.3280→+2.7586/+2.7071%로악화되고완료청산은전후0회다. 평가수익차이지성공청산표본증가가아니다.
- QQQ2024Q3 crossing은10/20bp−0.0223/−0.1461→+0.6057/+0.5644%지만청산1→0,평균투자12.9969→6.4332%다. 낮은노출과기말잔여평가이익을함께기록하며청산설계개선으로판정하지않는다.
- QQQ2025Q4 hysteresis1pp는10/20bp+0.2625/+0.2096→−0.9810/−1.0364%,평균투자는26.2829→18.4284%로감소했다. 낮은노출만으로안전성/성과우월성을주장하지않는다. SPY는두비용·모든분기에서추가효과가없었다.

따라서 **확정소유기반level교정은적용하고 crossing/1%p를공통기본값으로채택하는가설은기각**한다. 선택기능과실패·인과fixture는유지하되기본은level/0이다. 여러threshold/간격조합을최적화하거나사후최고수익값을선정하지않았다.

## 재현과 한계

기준harness는.cache의Git archive86a9829/src-tauri,현재harness는현재src-tauri를pathdependency로사용하고각baseline_runner.rs/runner.rs를실행한다. 기본조건을바꾸지않고baseline→current→validate.py순서로실행한다. 원본/runner/생산source해시는validation에보관한다. 파일이필요한bare.cache Cargo manifest와코드의경로는실행기source에서확인할수있으며캐시를커밋하지않는다.

선택된상관ETF3개의이미관측한가격이며독립OOS/통계유의성증거가아니다. 미사용2026을unseen증거라고주장하지않는다. 거래소달력·coverage·조정가격/실배당·실FX·장중경로/실체결은별도검증이다. same-input-quantity보유비교는실제%노출이같지않고same-accepted-path비용복원은독립알파benchmark가아니다. 실제주문·자동매매시작·계좌설정변경은하지않았다. UI/실패회귀·전체검증과코드/문서감사는 [작업기록](../../tasks/momentum-feedback-20261020.md)에구분한다.
