# P2-02 RSI: 실제 소유와 단독 추세·손절·보유 후보

상태: 생산 구현·후보 실행 및 기록 정산 완료. 운용 기본period14/30/70·선택옵션0을 유지하며 후보를 자동 적용하지 않는다.

## 설계와 재현

[설계](design.json)를 후보 실행 전에 고정했다. [baseline 실행기](baseline_runner.rs)는 archived978640c(v17), [현재 실행기](runner.rs)는 현재 생산 Rust preview를 사용한다. [정산 검증](validate.py)은 실제 기록된 체결·현금·노출을 대조하며 RSI 신호를 새로 만들지 않는다. fixed 입력은 [전수 연구 원본](../strategy-review-20261018/input.json) SHA256 d48ce5b59b7876c0a1457121e877fdc1117a77f990b4ec07ce649c92fe153317 이다. broker/계좌·설정·민감자료를 읽지 않는다.

평가는2023-01-03~2025-12-31 752일봉, strict 이전252봉(2021-12-31~2022-12-30), 최초요청수량 SOXQ51/SPY2/QQQ3, 초기자본1천만원·고정환율1450·tax0·배당/FX시나리오없음·overlay stop/takeprofit0이다. nextOpen, fee/slippage각10/20bps와기존공통guard/risk/maxPositionRatio0.3을고정한다. 수량은2022-12-30종가와초기자본15%로미리정하며비용별로바꾸지않는다.

기존 계산은14가격변화의단순평균이며Wilder방식이아니다. 손실평균0이면횡보도100이다. Buy는prev≤oversold/cur>oversold, Sell은prev≥overbought/cur<overbought이며매관측이전RSI를갱신한다. 보유/추세/guard거절뒤기존교차를래치해서재시도하지않는다. stop→cap→원래cross순서이며stop/cap만조건이지속되고실보유잔량이있으면다시후보를낸다. 종가등관측뒤nextOpen·갭/비용·주문제한때문에3%나63은실제손실/보유시간상한이아니다.

추세는이전같은주기의입력관측이며실시간첫관측에서추세용사전자료만비운다. RSI의기존warmup을재해석하지않는다. 약10초관측200개와일봉200개는다르다. 보유age는실제양수체결뒤0,다음owned관측1부터세며sameqty/partial/재설정/초기화로되감지않는다. origin/유효exactowner metadata없는복원은unknown이고활성cap에서다음owned관측보수적청산후보를내며가짜나이를붙이지않는다.

5조건×3ETF×두비용의30연속원장과500+252대조30회,각조건12분기초기화360원장을검증한다. 분할대조는같은경로재실행으로독립성과표본에더하지않는다. 독립분기는새자본으로시작하며수익률을합산/복리하지않는다. 2026가격은기본호환1224에포함되지만새후보성과에서제외한다. 이미보았던과거가격/상관ETF3/작은청산표본/고정FX·무배당/미인증시장달력·조정가격범위한계가있어사전등록·미관측OOS·통계적우수성·실운용안전성을주장하지않는다. 그리드/조합/성과를본임계값재조정은하지않는다.

## 검증과 남은 조건

부모정산은390원장의정확한조합/중복/경계와nextOpen·방향별슬리피지·현금/원가/실현/잔여·MDD/회전/노출/기말청산·기록수량경로복원61,782개산술검사를통과했다. 합성기능fixture와실제동결가격의진단을구분하며실제계좌/provider/주문/시장체결검증은하지않았다. 별도stock_analyst의독립감사는 [감사 산출물](independent-audit.json)과 [작업 기록](../../tasks/rsi-policy-20261022.md)에 기록한다.

재현은프로젝트.cache에978640c git archive와Cargo harness를두고baseline_runner를archivedsrc-tauri,current runner를현재src-tauri pathdependency로실행한다. argv는저장소경로이며target은공유target이다. validate.py는전체기록을gzip(lossless,mtime0)로보관하고평문을ignoredcache로옮긴다. 그뒤analyze.py가정책/기간별관측만집계한다. baseline-source-validation.json은archived코드주요파일이gitobject와정확히같음을증명한다. runtime수정후재실행시기록/코드hash를다시대조한다.

실제소유교정만기본동작에반영하고선택필터200/3/63은자동적용하지않는다. 원래RSI14/30/70·새옵션0과공통주문제한을유지한다. P1-05/P2-12 실제자료와다른열린전략연구는별도조건으로남는다.
